# OWASP: rà requirements và checks theo nhu cầu khách hàng

Review đủ 69 thành viên; deployment/dependency dùng chung evidence với Basic/Hardening. KEEP là giữ scoped claim, chưa là chứng nhận detector. Không sửa source behavior.

## Các lỗi thiết kế cần ưu tiên

- Chạy observations mặc định dù requirement cần human evidence; giữ human gate và tạo finding lane riêng.
- Root synthetic probe: 8 detectors trả PASS cho missing/empty/over-1MiB scope: 24 misleading PASS. Same readable risky snippet cho 8 FAIL. Xem focused-source-scope-observations.json. Human gate vẫn bảo vệ requirement.
- CodeInventoryCollector.php:16 bỏ root thiếu và >1MiB không manifest; source families skip read=false. Cần explicit completeness, phân biệt no-sink với không quan sát được.
- TemplateRequestSourceChecks.php:189-202: any PHP signature signal loại XML failures ở endpoint khác. Source-inspected, chưa reproduction riêng. Bind route/service/class/guard.
- AuthorizationSourceChecks.php:472-489: getCustomerId/isLoggedIn/keyword toàn file không chứng minh ownership. Need two-user IDOR fixture.
- InputSafetySourceChecks.php:871-888: client MIME/size/destination keywords chưa chứng minh upload validation; unrelated nearby guard gây false negative.
- InputSafetySourceChecks.php:366-396: PDO construction/direct API flag dù parameterized safe; cần candidate claim và triage.
- DI/static/logrotate/dependency selection/latest stable phải readiness/policy lane, không ngang CVE.
